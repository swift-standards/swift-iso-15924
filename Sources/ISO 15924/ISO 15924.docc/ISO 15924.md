# ``ISO_15924``

@Metadata {
    @DisplayName("ISO 15924")
    @TitleHeading("Swift Standards")
}

Represent ISO 15924 alphabetic and numeric script codes as validated Swift
values, with complete generated registry accessors and mappings.

The generated declarations are the package's canonical registry snapshot.
When the authoritative ISO 15924 registry changes, update the alphabetic and
numeric accessors, their `CaseIterable` collections, and both directions of the
mapping together so consumers cannot observe a partially updated registry.
